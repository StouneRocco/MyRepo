API de la maquette ESEO

Ouvre Connexion → POST /api/login, clique Try it out, saisis ton identifiant et ton mot de passe, puis Execute. Le jeton reçu est appliqué automatiquement aux appels suivants.

Tu peux aussi coller un jeton dans Authorize, sans ajouter « Bearer ». Les commandes de projection nécessitent un compte opérateur ou administrateur.
